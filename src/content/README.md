# 프로젝트 등록

현재 프로젝트는 `projects.ts`에서 관리합니다. UI와 상세 본문은 `../i18n/ko.ts`, `../i18n/en.ts`의 `projectItems`에 같은 slug로 추가합니다.

- `type`: 결과물 유형. 실제 필요한 코드를 두 언어의 `projectTypes`와 `PROJECT_TYPE` 공통 코드에 추가합니다. 현재 `website`(웹), `hybrid_app`(하이브리드 앱)이 있습니다.
- `origin`: 작업 배경. `personal`(개인), `education`(교육), `company`(회사).
- `isVisible`: true인 프로젝트만 홈·목록·상세에 노출합니다. false인 프로젝트는 상세 주소로도 조회되지 않습니다.
- `thumbnail`: 선택적인 public 이미지 경로(예: `/images/project.webp`). 값이 있으면 이미지만, 없으면 궤도 그래픽과 한 줄 말줄임 제목을 썸네일에 표시합니다.

목록 필터는 공개 데이터에 사용된 유형만 표시하며 유형이 하나 이하면 생략합니다. 검색 URL에는 번역된 이름 대신 안정적인 코드(예: `?category=website`)를 사용합니다.

학원·회사 프로젝트를 추가할 때 목적, 기간, 팀 규모, 본인 역할, 해결한 문제와 결과, 기술 및 공개 가능한 링크를 본문에 정리합니다. 회사 자료는 공개 가능한 범위만 사용합니다. 개발 모드의 `/admin`에 등록·수정 화면 초안이 있으며 DB와 공개 사이트에는 반영되지 않습니다. 새로고침·메뉴 이동 시 임시 변경은 초기화됩니다.

프로젝트는 시작일 최신순으로 표시하고, 시작일이 없는 프로젝트는 뒤에 둡니다. 홈은 앞의 2개만 노출합니다. `placeholder` 작업은 임시 데이터이며 실제 참여 내용이 준비되기 전까지 유형을 생략합니다. 카드와 상세에는 별도 진행 상태를 표시하지 않고, 종료일이 있으면 기간의 종료 날짜로 완료 여부를 알 수 있습니다. 현재 등록 데이터에는 썸네일이 없어 기본 궤도 그래픽을 사용합니다.

## 2026-10-21 공개 프로젝트 DB 조회 연결

홈 카드·프로젝트 목록·상세 및 상세 메타데이터는 server/services/projects.ts에서 개발/운영 환경의 DATABASE_URL로 조회한다. Project.isVisible=true인 행만 읽고 시작일 내림차순으로 정렬하며, 시작일이 없는 행은 뒤에 둔다. 홈은 앞의 2개를 표시한다. 공통 코드 표시명과 ProjectTranslation의 ko/en 내용을 사용하고, 영어 누락 시 한국어로 대체한다. 상세에는 원문 표시 안내를 제공한다. src/content/projects.ts와 언어 사전의 프로젝트 항목은 seed 자료로 유지한다.

이제 홈·프로젝트 화면에는 DB 연결이 필요하다. 로컬은 SSH 터널, 운영은 별도 운영 DATABASE_URL과 migration/seed를 먼저 준비해야 한다. DB 실패 시 오류 화면을 표시하며 TS 예시 데이터로 대체하지 않는다.

## 2026-10-22 프로젝트 기간

기간은 `Project.startedOn`과 `Project.endedOn`에 저장한다. 목록 카드와 상세 속성, 관리자 목록·편집 화면에서 표시하고, 입력하지 않은 기간은 비워 둔다. 월만 확인된 기간은 해당 월의 1일을 저장해 `YYYY.MM`으로 표시한다. 일자까지 확인된 기간은 `YYYY.MM.DD`로 표시하며, 종료일이 비어 있으면 `현재`로 나타낸다.

## 프로젝트 카드 정보

카드는 공통 `ProjectCard`를 사용한다. 커버에는 썸네일 또는 그래픽만 두어 제목 중복을 피하고, 정보 영역에는 제목·기간·기술 태그를 최대 3개까지 표시한다. 진행 상태는 표시하지 않으며, 종료일은 기간 끝 날짜로 나타낸다. 기술 목록은 `TECHNOLOGY` 공통 코드에서 선택한다.
