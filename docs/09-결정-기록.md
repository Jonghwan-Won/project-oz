# 결정 기록과 공식 참고자료

날짜별 당시 결정과 변경 이력입니다. 과거 선택은 이후 결정으로 대체될 수 있으므로 현재 동작의 기준으로 사용하지 말고, README와 해당 기능의 현행 문서를 참고하세요.

## 2026-10-21 소개 상세 편집형 레이아웃

- 소개를 큰 헤드라인·정적인 OZ 입자 비주얼, 작업 방식 두 단락, ddoza 이름 속 oz를 강조한 별명 이야기, 모든 제작 도구를 유리구두로 소개하는 섹션으로 재구성했다. 메인과 같은 입자 좌표를 재사용하며 상세에서는 애니메이션 없이 서버 SVG로 표시한다.
- 프로젝트·게시판으로 이어지는 버튼을 추가하고 한국어·영어를 함께 갱신했다. 관리자 DB 저장은 연결하지 않았다.

## 2026-10-21 모든 제작 도구를 유리구두로 표현

- 사용자의 의미 정리에 따라 Codex뿐 아니라 제작·운영 도구 전체를 생각을 현실로 옮기는 유리구두로 소개한다. 메인 하단은 로고·이름 중심의 정적 타일로 줄이고 개별 설명·외부 링크·화살표·호버 반응을 제거했다.
- Synology 로고는 사용자가 지정한 공식 브랜드 페이지의 기본 2색 SVG로 교체했다. 원본 비율과 색상을 유지하고 공식 최소 표시 너비 80px 이상을 확보한다.

## 2026-10-21 Board 기준 공통 카드 반응

- 프로젝트·게시판·문의·도구 카드를 공통 interactiveCard 스타일로 통일했다. 26px 둥근 모서리와 0.2초 배경 전환, 호버/키보드 포커스 시 2px 상승만 적용한다. 프로젝트에 추가했던 그림자·강조 테두리·내부 확대·화살표 이동은 제거했다. 동작 줄이기 설정에서는 상승을 끈다.

## 2026-10-21 프로젝트 카드 반응과 모션 입력 정리

- 메인 입자 모션의 포인터 추적을 제거했다. 공통 프로젝트 카드는 호버·키보드 포커스 때 5px 상승, 강조 테두리·그림자·옅은 바이올렛 정보 배경을 적용한다. 기본 그래픽/실제 썸네일은 미세 확대하고 화살표도 이동한다. 동작 줄이기 설정에서는 이동·확대·전환을 끈다.

## 2026-10-21 OZ 입자 히어로 시안

- Recraft·if kakao·Daker 레퍼런스에 대한 후속 요청으로 메인을 설명형 패널에서 전면 브랜드 비주얼로 변경했다. 잉크색 배경·블루/바이올렛 입자가 처음부터 OZ를 이루고, 구형으로 흩어졌다 다시 모이는 Canvas 모션이다. 이전 모션 파일과 소개 상세의 정적 그림은 보관한다.
- 히어로 안에서만 라임 대신 바이올렛 강조와 버튼을 사용한다. 별도 3D 의존성 없이 기존 React·Canvas로 구성하며 정지/재생·동작 줄이기·화면 밖 렌더링 생략·해상도 상한을 적용한다.

- 소개 상세의 기존 판타지 이미지는 노출하지 않고 같은 그래픽의 정적인 완성 장면을 사용한다. 과거 이미지 파일은 보존한다. 본문은 작은 필요를 구현하고 과정을 기록하는 작업실에 맞추고, 사용자 제공 별명 유래(금방 또 잠들어서 또자)를 짧은 개인 이야기로 반영했다.

- 메인 구성·모션은 코드에서 관리하고 상세 제목·본문·대표 비주얼 선택은 향후 관리자 콘텐츠로 분리하는 방향이다. 현재 문구는 기존 언어 사전에 있으며 관리자 저장·DB 연결은 이번 범위에 포함하지 않는다.

## 2026-10-21 Alert 간소화와 맨 위로 이동

- 모든 페이지 오른쪽 아래에 공통 Button으로 ↑ 버튼을 고정한다. 앵커 링크는 URL 해시를 남기고 동일 해시 재클릭 시 이동하지 않아, 클릭마다 window.scrollTo를 호출하도록 수정했다. behavior: auto로 기존 CSS의 부드러운 스크롤·동작 줄이기 설정을 따른다.

## 2026-10-21 공통 UI 이름과 Alert 디자인 시안

- 사이트 전용 공통 UI는 OzAlert, 향후 OzConfirm·OzDataGrid·OzDataEditGrid처럼 Oz 접두사를 사용한다. 현재 Alert 파일과 export·사용처·문서를 OzAlert로 맞추고, 다른 기존 UI나 아직 만들지 않은 컴포넌트는 일괄 변경·선행 생성하지 않는다.
- 개발 전용 /guide/alert-designs에서 Signal·Companion·Float 세 외형을 비교한다. 현재 공통 OzAlert의 디자인은 선택 전까지 유지하며 시안은 비동작 목업으로 표시한다.

## 2026-10-22 공용 UI 이름 규칙

- 기존 Oz 접두사 결정을 대체하고, 재사용 UI의 파일명·export·호출부는 `Common` 접두사로 통일한다. 예: CommonAlert, CommonInput, CommonSelectBox, CommonButton.
- 기존 공용 컴포넌트만 이름을 바꾼다. 아직 공용 구현이 없는 Grid·Checkbox·Radio 컴포넌트는 이름 규칙을 이유로 새로 만들지 않는다.

## 2026-10-21 사이트 전용 공통 Alert

- 사용자 선호: 공통 UI의 외형은 프레임워크 기본 테마보다 사이트 전용 디자인을 우선한다. 접근성·키보드 동작을 위한 브라우저 기능이나 기존 헤드리스 도구의 재사용과는 구분한다.
- 공통 Alert는 브라우저 dialog의 모달 동작을 사용하고 외형은 사이트 토큰·공통 Button으로 직접 디자인한다. UI 프레임워크와 전역 알림 매니저는 추가하지 않는다.
- 제어형 open/onClose로 한 곳의 상태를 유지한다. 확인과 Escape 닫기, 포커스 복귀, 배경 스크롤 제한을 제공하며 가이드의 저장 완료·오류 안내는 실제 데이터 변경 없는 예제다.

## 2026-10-21 가이드 Markdown 뷰어와 환경 구조도

- 환경 가이드 한 화면에 공개 인터넷·Tailscale·집 내부망·NAS의 경계를 나타내는 네트워크 구조와 선택 과정 6단계를 함께 제공한다. GitHub Actions도 Docker로 빌드한다는 점과 NAS 직접 빌드 성능은 측정하지 않았다는 점을 명시한다.
- 기존 개발 전용 가이드에 별도 문서 뷰어와 환경 구조도를 연결한다. production에서는 하위 경로도 서버에서 404로 차단한다.
- Markdown 문법 전체를 직접 파싱하지 않고 react-markdown과 remark-gfm을 사용한다. 원시 HTML은 무시하고 이미지는 자동 요청하지 않는다. 파일은 UTF-8, 최대 1 MiB로 제한하고 브라우저 메모리에서만 읽는다. DB·서버 업로드 저장은 추가하지 않는다.
- 저장소의 README와 docs의 번호 있는 일반 파일만 읽는다. 개인 작업일지는 사이트에 포함하지 않고, 확인한 환경을 민감 정보 없이 docs/11-환경-구축-기록.md와 구조도로 요약한다.

## 2026-10-21 첫 NAS 웹 배포 준비

- PC와 NAS에서 빌드 도구를 추가하지 않고 GitHub Actions에서 기존 Dockerfile로 linux/amd64 이미지를 생성한다. 실제 컨테이너 검사 후 전체 커밋 SHA 태그로 GHCR에 게시하며 NAS 배포는 수동으로 진행한다.
- 첫 공개 UI는 운영 DB·migration 없이 실행한다. NAS 웹 포트는 127.0.0.1:13000에만 바인딩하고 DSM HTTPS 역방향 프록시를 사용한다. 개발 가이드와 테스트 API의 production 404를 이미지 검사에 포함한다.
