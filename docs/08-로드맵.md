# 로드맵

이 문서는 현재 구현 이후의 남은 제품·운영 작업만 관리합니다. 완료된 기능의 상세 현황은 [현재 구현 상태](10-현재-구현-상태.md), 각 기능의 동작은 해당 기준 문서를 참고합니다.

## 운영 배포 이후 남은 일

운영 배포와 최초 콘텐츠 이관은 완료된 상태입니다. 구성과 기능 범위는 [현재 구현 상태](10-현재-구현-상태.md)를 따르며, 실제 운영 상태는 별도로 검증합니다.

- 최종 이관 후 로그인·비관리자 권한·공개 범위·이미지·첨부 다운로드 재확인
- 한영 분류명·운영 확인창 확인, 운영 전용 공통코드 비교
- 백업의 별도 DB 복원 연습과 외부 사본 확보
- migration 이미지 OpenSSL 감지 경고 정리
- NAS 재시작 후 복구, DB IP 변경에 덜 의존하는 관리 접속 방식 확인
- 검증 후 이전 컨테이너·이미지·이관 자료 보관 정책 정리

상세 순서는 [배포·운영](06-배포-운영.md)을 따릅니다.

## 제품 후속 작업

- 관리자 페이지 전체를 지정 관리자 로그인 후에만 접근하도록 전환(후속 작업, 현재는 읽기 전용 미리보기 제공)
- 공개 프로필·경력·연락처를 확인된 자료로 채우기
- 개인 정보 보유·삭제 안내와 문의 보관 정책 결정
- 서버 측 검색·페이지네이션은 목록 규모가 실제로 커질 때 검토
- 예약 발행·AI 초안·배치 작업은 별도 요구와 운영 격리를 결정한 뒤 착수

코드 놀이터, DB 놀이터, 예약 작업 현황은 아이디어/설계이며 현재 배포 기능으로 취급하지 않습니다. 자세한 내용은 [아이디어](13-아이디어.md), [놀이터 설계](12-놀이터-설계.md), [자동화 설계](07-자동화-설계.md)를 참고하세요.
