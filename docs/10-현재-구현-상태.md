# 현재 구현 상태

이 문서가 기능 구현 현황의 기준입니다. 운영 배포 여부와 실제 NAS 상태는 별도로 확인해야 하며, 과거 작업 기록은 [결정 기록](09-결정-기록.md)과 [환경 구축 기록](11-환경-구축-기록.md)에 둡니다.

## 구현됨

- Next.js standalone 웹 앱, 한국어·영어 UI, 공개 페이지와 반응형 화면
- PostgreSQL/Prisma 스키마와 migration, 공개 프로젝트·게시글의 DB 조회
- 관리자 프로젝트·게시글 등록/수정/논리 삭제, 검색과 목록 UI
- 문의 접수(비로그인 포함), 관리자 문의 및 공통코드 관리
- GitHub OAuth와 DB 세션. `GITHUB_ADMIN_ID`에 지정된 계정만 관리자로 인정
- 파일 업로드·조회·첨부 관리와 공개/비공개 콘텐츠 연결에 따른 접근 제어
- 관리자 미리보기는 비관리자에게 읽기 전용으로 제공되며, 변경은 서버 권한 검사
- GitHub Actions의 lint/typecheck/test/Prisma 검사/build와 GHCR `linux/amd64` 이미지 게시
- 개발 전용 `/guide`, `/api/guide`와 내부 Markdown 문서 뷰어는 production에서 차단

## 운영에 아직 필요한 설정·검증

- 새 도메인, DNS/DDNS, 외부 연결, TLS 인증서와 역방향 프록시
- 운영 전용 OAuth 앱·callback·환경변수와 운영 PostgreSQL 연결
- 운영 migration 실행 도구/명령, 영속 파일 볼륨과 백업 구성
- 별도 위치로 백업 복원 연습, NAS 재부팅 후 복구 및 장시간 안정성 확인
- 운영에서 로그인, 비관리자 제한, 프로젝트/게시글 표시, 파일 권한 확인

## 현재 제한

- NAS 자동 배포는 구성돼 있지 않습니다. Actions가 이미지를 게시하고 NAS 업데이트는 수동입니다.
- `/api/health`는 DB 연결을 검사하지 않습니다.
- 이메일 답변 발송, 예약 발행, AI 생성/자동 게시, 코드·DB 놀이터는 구현 범위가 아닙니다.
- 서버 검색/페이지네이션 전환은 데이터량에 따라 검토할 후속 항목입니다.

구체적인 운영 순서는 [배포·운영](06-배포-운영.md), 접근 제어는 [접근 정책](16-접근-정책.md)을 기준으로 합니다.
