# 현재 구현 상태

이 문서가 기능 구현 현황의 기준입니다. 운영 배포 여부와 실제 NAS 상태는 별도로 확인해야 하며, 공개 가능한 기술 결정과 환경 구성은 [결정 기록](09-결정-기록.md)과 [환경 구축 기록](11-환경-구축-기록.md)에 둡니다.

## 구현됨

- Next.js standalone 웹 앱, 한국어·영어 UI, 공개 페이지와 반응형 화면
- PostgreSQL/Prisma 스키마와 migration, 공개 프로젝트·게시글의 DB 조회
- 관리자 프로젝트·게시글 등록/수정/논리 삭제, 검색과 목록 UI
- 문의 접수(비로그인 포함), 관리자 문의 및 공통코드 관리
- GitHub OAuth와 DB 세션. `GITHUB_ADMIN_ID`에 지정된 계정만 관리자로 인정
- 파일 업로드·조회·첨부 관리와 공개/비공개 콘텐츠 연결에 따른 접근 제어
- 관리자 미리보기는 비관리자에게 읽기 전용으로 제공되며, 변경은 서버 권한 검사. 첨부 원본 파일명과 파일명 검색은 관리자 전용
- GitHub Actions의 lint/typecheck/test/Prisma 검사/build와 GHCR `linux/amd64` 이미지 게시
- 공통 UI 가이드는 공개, 내부 Markdown 문서와 환경 구조도는 관리자 전용, DB 진단 API는 개발 관리자 전용

## 운영 구성

운영 배포와 최초 콘텐츠 이관은 완료된 상태입니다. Cloudflare Tunnel, 운영용 GitHub OAuth, PostgreSQL, 영속 파일·로그 볼륨을 사용합니다. 실제 배포 SHA, 데이터 수량, 컨테이너 이름과 백업 위치는 비공개 운영 기록으로 관리합니다. 이 문서는 실시간 서버 상태를 보증하지 않습니다.

## 운영에 남은 검증

- 최종 이관 후 로그인·비관리자 제한·콘텐츠 공개 범위·이미지·첨부 다운로드 재확인
- 한영 분류명과 운영 확인창 표시, 운영 전용 공통코드 비교
- migration 이미지 OpenSSL 감지 경고 정리
- 별도 DB 백업 복원 연습, 외부 백업 및 NAS 재시작 후 복구 확인
- 이전 컨테이너·이미지·이관 자료 보관 정책과 DB IP 의존성 정리

## 현재 제한

- NAS 자동 배포는 구성돼 있지 않습니다. Actions가 이미지를 게시하고 NAS 업데이트는 수동입니다.
- `/api/health`는 DB 연결을 검사하지 않습니다.
- 이메일 답변 발송, 예약 발행, AI 생성/자동 게시, 코드·DB 놀이터는 구현 범위가 아닙니다.
- 관리자 프로젝트·게시글 검색은 URL 조건으로 서버 DB를 조회합니다. 추가 페이지네이션 개선은 데이터량에 따라 검토합니다.

구체적인 운영 순서는 [배포·운영](06-배포-운영.md), 접근 제어는 [접근 정책](16-접근-정책.md)을 기준으로 합니다.
