## 확인한 공식 문서 (2026-10-20 조회)
- Next.js self-hosting: https://nextjs.org/docs/app/guides/self-hosting
- Next.js authentication: https://nextjs.org/docs/app/guides/authentication
- Prisma production migration: https://docs.prisma.io/docs/cli/v7/migrate/deploy
- Prisma migration commands: https://docs.prisma.io/docs/cli/migrate
- Docker multi-platform: https://docs.docker.com/build/building/multi-platform/
- Synology Container Manager 지원 모델: https://www.synology.com/en-in/dsm/packages/ContainerManager

자료에서 확인한 사실: Next self-hosting은 역방향 프록시를 권장한다. 인증과 인가를 구분하고 데이터 접근 계층에서 검사할 것을 권장한다. Prisma migrate deploy는 운영용 pending migration 적용 명령이다. Docker 이미지 플랫폼은 호스트 아키텍처와 맞아야 한다. DS218+는 Container Manager 지원 목록에 있다.
이 자료는 설계 선택의 근거이며 설치·빌드·실제 장비 호환성 검증을 대체하지 않는다.
